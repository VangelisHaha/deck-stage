Welcome · 先说清楚

这是一份示例稿，用来展示 DeckStage 能做什么

整份稿子就是一个文件夹里的 HTML。下面几页依次演示：入场动画、数字滚动、打字机、图表、演讲者视图、遥控与导出。

怎么放

你正在看的就是放映效果。主屏全屏给观众，演讲者窗口留在本机，翻页自动同步。

怎么写

不用手写。装上配套的 skill，对 Agent 说一句「做一份关于 xxx 的演示稿」就行。

怎么删

看完不需要了，在稿库里把「DeckStage 示例」这个稿库目录点 × 移除，示例稿会一并删掉。

别人给你的稿子、你自己写的稿子，都是这样的一个文件夹。改完保存，重新放映就是最新的，没有浏览器缓存问题。

Agent · 新建与修改

稿子交给 Agent，你只管讲

DeckStage 不提供编辑界面，新建和修改都由配套的 skill 完成。

1 装 skill

稿库里点「新建 / 编辑 → 安装 skill」，复制提示词给你的 Agent。

2 说需求

「做一份关于 xxx 的演示稿」「第 3 页加一张图」「改一下台词」。

3 体检

skill 自带体检脚本，改完先过体检，再让你看。

4 放映

回到稿库，选中，回车。

框架固定，风格每份稿子自己定。配色、字体、动效都在稿子自己的样式里，不受框架限制。
