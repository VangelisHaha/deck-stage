01

让 Agent 做 PPT，难在哪

三个难处，每一个都和 .pptx 这种格式有关。

Problem · 为什么又贵又丑

格式本身，就不是给 Agent 设计的

Agent 最擅长写文本和代码，而 .pptx 是一堆要逐个指定坐标的二进制对象。

要算坐标

每个元素都要指定位置、宽高、字号。改一处间距，下面一片都要重算。

看不见结果

写完要渲染成图片才知道好不好看，来回几轮，每一轮都花 token。

动画写不出

入场、联动、逐条出现，在 .pptx 里几乎没法用代码声明。

不是 Agent 不会做，是格式在拖后腿。

02

换成 HTML，就都好说了

Agent 最熟悉的语言，加一个专门放映的壳。

Approach · 写法

一页就是一个 section

排版交给浏览器，动画就是 CSS，整份稿子是纯文本。

不用算坐标

flex 和 grid 自动排版，改一句话不会牵动整页。

动画没有上限

阶梯入场、缩放、滑入是内置的；CSS、SVG、Canvas 想用什么用什么。

改动看得清

纯文本，git diff 一眼看出改了哪一页。

这一页的每个卡片，都是依次入场的。 翻到别的页再翻回来，动画会重播。

Stage · 放映

放映的时候，像个发布会

DeckStage 把浏览器放映的麻烦都处理掉了。

双屏

观众窗口全屏到外接屏，演讲者窗口留在本机，翻页自动同步。

手机遥控

手机扫码，翻页、看台词、跳页、黑屏，不用装 App。

投屏友好

没有地址栏和多余信息，飞书里共享窗口，演讲者窗口不会被看到。
