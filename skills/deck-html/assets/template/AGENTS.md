## 文件结构

默认是单文件结构（`index.html` + `notes.js`）。页数多、改一处要读很多上下文时，按 `references/split-deck.md` 拆分，并把拆分后的结构写在这里。

## 放映与体检

```bash
python3 <SKILL_DIR>/scripts/check_deck.py .        # 每次改完都跑，0 error 才算完（拆分稿用 check_split.py）
```

放映：用 DeckStage 打开，或 `./serve.sh`。

## 改动流程

1. 文案、结构、删页先给方案，等确认再动手。配色、错别字、补降级规则可以直接改。
2. 改页面文案要同步 `notes.js` 里对应的台词；增删页后复查跨页引用（「前面那 13 个」「刚才那张表」）和总数。
3. 不逐页截图验证。改完跑体检，告诉用户改了哪几页、重点看什么。
4. 新增 `background-clip:text` 的选择器，必须登记到 `deck.config.js` 的 `gradientText`。
