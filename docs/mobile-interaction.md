# Android 遥控交互约定

Android 是桌面 DeckStage 放映的遥控器。入口、扫码、配对、等待放映、遥控和失败恢复使用同一套交互。

## 连接流程

1. 首页以「扫码连接」为主操作，输入地址为备用操作。
2. 点击扫码才请求相机权限。相机离线识别电脑「手机遥控」面板的二维码，识别成功即关闭相机并连接电脑。
3. 二维码自带配对令牌，无需再输入配对码；手动地址进入 6 位配对码页面。
4. 未开始放映时显示「等待放映」，开始后自动切到遥控页。
5. 取消扫码回首页；权限被拒时给中文提示，保留手动入口。不相关的二维码不会打开网页。
6. 遥控页左上角「更换电脑」及系统返回键均回到首页。连接失败可重试或更换电脑。

相机只在扫码页运行，退出后由扫描组件释放。地址历史只存电脑地址，不存二维码令牌。

## 统一样式

- 颜色与字体以 `src/remote/remote.css` 为唯一来源：黑色背景、米白正文、橙色主操作、灰色说明和分隔线。
- 连接页复用该 CSS，仅在 `mobile/www/connection.css` 补页面布局。
- `mobile/scripts/prepare-web.cjs` 在同步前复制公共 CSS，并生成 Android 颜色资源。
- 主操作用橙色实心按钮；备用操作用米白描边按钮；原生返回入口使用黑底米白文字。
- 大标题沿用衬线字体，说明用无衬线字体，页码和标记用等宽字体。
- 原生扫码与遥控页使用 `RemoteTheme` 公共方法生成返回按钮、标题和错误弹窗。

## 验证范围

必须检查扫码入口、相机权限、取消返回、非遥控二维码、识别结果自动连接、手动配对、翻页、跳页、黑屏、前台音量键及失败重试。构建成功与扫描页面出现，都不能单独证明实际相机识别完成。

## 台词阅读布局

放映中以演讲台词为主体。顶部页码、计时缩为一行，标题保持一行，底部只常驻上一页、下一页和更多。正文默认 28px，可在更多操作中以 2px 步长调整到 20–40px，并记住选择。台词过长时仅滚动正文，翻页按钮固定可见。

黑屏、跳页、震动和按键映射放入更多操作，不挤占台词区域。原生 App 将这套遥控界面一起打包，配对令牌、cookie、状态流和命令仍由电脑服务处理；升级 APK 即可更新界面，无需等待电脑端页面升级。
