稿库

⌘F

    投屏光标

    鼠标移入演讲者画面时，观众屏幕会看到这个光标。

    选择样式
    光标大小小号适合日常投屏
    设置会保留到下次放映

    添加远端目录

    稿子在另一台 Linux / Mac 上时，填这台机器的 SSH 登录信息。放映和导出前会自动同步到本机。

    连接信息会保存在本机，下次自动出现在稿库里，不用重输。密码加密后落盘（防明文，防不了能读你用户目录的人）。主机写 ~/.ssh/config 里的别名也行，此时用户名、端口、密钥按那份配置走。

    新建与编辑

    稿子由 Agent 用 deck-html skill 生成和修改，DeckStage 只负责放映，这里不提供编辑界面。

    01 · SKILLS 目录

    把整个 deck-html 目录装进你的 Agent 的 skills 目录即可。
